# 45 Days Abs Challenge

Practical 45-day progressive abs and core challenge app built with Expo / React Native.

## Phases
- **Foundation (1–10):** Form & Activation
- **Build (11–25):** Strength & Volume
- **Intensify (26–40):** Density & Control
- **Peak (41–45):** Finish Strong

## Features
- Full progressive 45-day workout plan (all days defined)
- Daily streak tracking
- Progress calendar
- Local persistence with AsyncStorage
- Dark UI

## Run
```bash
npm install
npx expo start
```

Bundle ID: `com.momentum.abs45`
